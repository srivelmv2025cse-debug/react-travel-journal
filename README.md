# Elsewhere Travel Journal

A visual travel journal built with React and Vite. Its illustrated hero and trip cards create a magazine-inspired, responsive travel story.

## Components

- `JournalHeader` — section navigation and journal identity.
- `TripCard` — reusable postcard-style destination entry.
- `App` — composes the hero, journey grid, and footer from trip data.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
